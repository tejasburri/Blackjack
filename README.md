# Bash Blackjack
# Overview
Bash Blackjack is a terminal-based card game written in Bash. The player competes against a computer dealer and attempts to get as close to 21 as possible without going over.

This project is being developed to practice Bash scripting concepts such as variables, arrays, functions, loops, conditionals, and user input handling.
